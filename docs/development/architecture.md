1. Обзор архитектуры

Проект построен на разделении кода на слои. Зависимости направлены от внешних слоёв к внутренним.

2. Слои и их назначение

src/entities - модели данных

| Модель | Содержимое |
|---|---|
| роль | slug, name, description, roleDefinition, whenToUse, customInstructions, groups, source |
| правило | имя файла и содержимое |
| ignore-запись | шаблон |
| шаблон конфигурации | относительный путь и содержимое |

src/application - прикладная логика

- сборщики конфигурации для Zoo Code и Codex
- инициализация исходной конфигурации из шаблонов
- контракты чтения ролей, правил и ignore-записей
- контракты чтения шаблонов

src/infrastructure - инфраструктура

- чтение ролей из YAML
- чтение правил из Markdown
- чтение ignore-записей из текста
- чтение шаблонов пакета
- настройки окружения

src/cli - консольные команды init-uni-ai и build-uni-ai

src/templates - универсальные шаблоны конфигурации

3. Правила зависимостей

- модели данных не зависят от других слоёв
- прикладной слой зависит от моделей данных и контрактов, но не от инфраструктуры
- инфраструктура реализует контракты прикладного слоя
- команды связывают прикладную логику с реализациями репозиториев
