1. Поток данных

- init-uni-ai: шаблоны пакета -> исходная конфигурация config/agents
- build-uni-ai: исходная конфигурация config/agents -> нативные файлы инструмента

2. Инициализация

Команда init-uni-ai читает шаблоны пакета из src/templates и создаёт файлы в каталоге config/agents. Существующие файлы не перезаписываются.

3. Сборка

Команда build-uni-ai читает роли, правила и ignore-записи из config/agents и создаёт нативные файлы выбранного инструмента.
