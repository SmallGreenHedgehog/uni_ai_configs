1. Общие сведения

Команда build-uni-ai создаёт нативные файлы в корне проекта. Набор файлов зависит от выбранного сборщика.

2. Zoo Code

Создаваемые файлы:

- .roomodes - список режимов customModes
- .roo/rules/ - файлы правил
- .rooignore - ignore-шаблоны

Каталог .roo/rules пересоздаётся заново и содержит только файлы правил из исходной конфигурации.

| Элемент конфигурации | Файл результата |
|---|---|
| роли | .roomodes |
| правила | .roo/rules/ |
| ignore-записи | .rooignore |

Каждая роль превращается в запись режима с полями slug, name, description, roleDefinition, whenToUse, customInstructions, groups и source.

3. Codex

Создаваемые файлы:

- AGENTS.md - правила, объединённые в один файл
- .codex/config.toml - секции агентов agents.<slug>
- .codexignore - ignore-шаблоны

| Элемент конфигурации | Файл результата |
|---|---|
| роли | .codex/config.toml |
| правила | AGENTS.md |
| ignore-записи | .codexignore |

Правила объединяются в AGENTS.md пустой строкой, в алфавитном порядке имён файлов. Для каждой роли создаётся секция agents.<slug> с полями description и prompt. Поле prompt объединяет определение роли, условия применения и инструкции, разделённые пустыми строками.

4. Общие правила

Сгенерированные файлы не редактируются вручную и исключены из Git.
