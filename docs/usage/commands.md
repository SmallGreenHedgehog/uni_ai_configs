1. Общие сведения

Пакет предоставляет две консольные команды: init-uni-ai и build-uni-ai. Обе выполняются из корня целевого проекта.

2. init-uni-ai

Назначение: разворачивает исходную конфигурацию агентов из шаблонов пакета в каталог, заданный через UNI_AGENTS_PATH.

Создаваемые файлы:

- roles.yaml - роли
- ignore - ignore-шаблоны
- rules/architecture.md - заглушка для описания архитектуры проекта
- rules/code-style.md - правила оформления кода

Существующие файлы не перезаписываются. Команда выводит списки созданных и пропущенных файлов.

Пример:

    init-uni-ai

3. build-uni-ai

Назначение: собирает нативную конфигурацию из исходного каталога UNI_AGENTS_PATH для сборщика, заданного через UNI_BUILDER.

Пример:

    build-uni-ai

Выбор сборщика без изменения .env:

    UNI_BUILDER=Codex build-uni-ai

Команда выводит сообщение об успешной сборке с перечнем созданных файлов.
