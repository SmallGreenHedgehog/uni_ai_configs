1. Правила

Правила - это Markdown-файлы в каталоге rules/. Каждый файл описывает отдельный свод требований, например архитектуру, стиль оформления кода, оформление коммитов или создание ветвей.

2. Стандартные правила

- architecture.md - заглушка для описания архитектуры проекта
- branches.md - правила создания ветвей и черновиков PR
- code-style.md - правила оформления кода
- commits.md - правила оформления коммитов

3. Порядок обработки

Файлы обрабатываются в алфавитном порядке имён. Имя файла сохраняется при сборке.
