1. Структура исходной конфигурации

Исходная конфигурация хранится в каталоге config/agents:

- roles.yaml - список ролей
- rules/ - Markdown-файлы правил
- ignore - ignore-шаблоны по одному на строку

2. Связанные разделы

- [roles.md](roles.md) - описание полей роли
- [rules.md](rules.md) - правила
- [ignore.md](ignore.md) - ignore-записи
